# Code of Conduct

We are a few people building small things. This is short on purpose.

## The rule

Be decent to people. Assume good faith. Argue about code without making it personal.

That covers almost everything. To be specific, these will get you removed:

- Harassment, threats, or personal attacks.
- Sexual language or imagery. Codekind teaches kids, so this one is absolute.
- Publishing someone's private information.
- Continuing to derail a discussion after being asked to stop.

## What happens if you break it

We will ask you to stop. If you carry on, we will remove you — closing your issues and pull requests, blocking your account, or both.

There is no committee and no appeals process. A maintainer makes the call. We would rather spend our time building things than running a tribunal.

## Reporting a problem

Email **hello@codekind.net**.

We do this alongside other work, so we cannot promise a response time. We will read it, we will take it seriously, and we will keep the fact that you reported it to ourselves.

## Where this applies

Our repositories — issues, pull requests, code review, commit messages — and anywhere someone is representing KindStack or Codekind in public.
